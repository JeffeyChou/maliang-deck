# Data Story Dashboard

## Use cases and case summary
GridPulse Energy Resilience Story supports energy and logistics KPI narrative for utility operations leaders and sustainability analysts. A data story connects demand response, outage minutes, fleet dispatch, and carbon intensity into an operating narrative.

## Typography
Use Space Grotesk for headlines, Inter for body copy, and Roboto Mono for metric labels or code-like annotations.

## Palette and color system
Primary #0B1120, secondary #ECFEFF, accent #06B6D4, and neutral #94A3B8. Use accent sparingly for energy signals.

## Component and material system
The system includes hero bands, evidence cards, metric charts, decision tables, and three-pillar operating model cards.

## Table and chart styling
Charts use the accent color for priority bars. Tables use high-contrast headers and concise cells tied to energy, outage, carbon, dispatch.

## Icon and shape system
Prefer simple rounded rectangles, thin separators, small badges, and geometric markers over decorative illustration.

## Spacing and alignment
Use a strong outer margin, a consistent title band, and aligned card grids. Keep dense content inside dashboard or table regions.

## Animation / FX / Static fallback
HTML may use element animation, slide FX, and runtime transitions. Static SVG/PDF/PPTX exports ignore motion and preserve the final readable layout.

## Design guidelines
Lead with the case decision, pair every metric with an interpretation, and keep each slide anchored in energy and logistics KPI narrative.

## Dos and don’ts
Do use concrete domain words such as energy, outage, carbon, dispatch, resilience, grid. Don’t use generic filler, vague placeholder copy, or ungrounded claims.

## Reference inspiration and provenance
This pack is a synthesized Maliang Deck design inspired by common energy and logistics KPI narrative communication patterns; it is not a pixel copy of any single reference.
