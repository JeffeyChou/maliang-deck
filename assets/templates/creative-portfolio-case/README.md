# Creative Portfolio Case

## Use cases and case summary
LumaNest Brand Redesign Case Study supports brand and product redesign case study for creative directors, product leaders, and portfolio reviewers. A design team shows brand strategy, identity system, packaging, and product surface decisions for a smart home redesign.

## Typography
Use Playfair Display for headlines, Inter for body copy, and IBM Plex Mono for metric labels or code-like annotations.

## Palette and color system
Primary #3B0764, secondary #FFF1F2, accent #FB7185, and neutral #78716C. Use accent sparingly for LumaNest signals.

## Component and material system
The system includes hero bands, evidence cards, metric charts, decision tables, and three-pillar operating model cards.

## Table and chart styling
Charts use the accent color for priority bars. Tables use high-contrast headers and concise cells tied to LumaNest, brand, identity, packaging.

## Icon and shape system
Prefer simple rounded rectangles, thin separators, small badges, and geometric markers over decorative illustration.

## Spacing and alignment
Use a strong outer margin, a consistent title band, and aligned card grids. Keep dense content inside dashboard or table regions.

## Animation / FX / Static fallback
This template is static-first. If HTML motion is added later, document the static SVG/PDF/PPTX behavior before approval.

## Design guidelines
Lead with the case decision, pair every metric with an interpretation, and keep each slide anchored in brand and product redesign case study.

## Dos and don’ts
Do use concrete domain words such as LumaNest, brand, identity, packaging, redesign, prototype. Don’t use generic filler, vague placeholder copy, or ungrounded claims.

## Reference inspiration and provenance
This pack is a synthesized Maliang Deck design inspired by common brand and product redesign case study communication patterns; it is not a pixel copy of any single reference.
