# Startup Pitch

## Use cases and case summary
OpsPilot AI Operations Platform Pitch supports AI operations platform startup pitch for seed investors, design partners, and GTM advisors. A founder pitches an AI operations copilot that automates incident triage, playbooks, and postmortem learning.

## Typography
Use Inter Tight for headlines, Inter for body copy, and JetBrains Mono for metric labels or code-like annotations.

## Palette and color system
Primary #18181B, secondary #FAFAFA, accent #A855F7, and neutral #71717A. Use accent sparingly for OpsPilot signals.

## Component and material system
The system includes hero bands, evidence cards, metric charts, decision tables, and three-pillar operating model cards.

## Table and chart styling
Charts use the accent color for priority bars. Tables use high-contrast headers and concise cells tied to OpsPilot, AI, incident, playbook.

## Icon and shape system
Prefer simple rounded rectangles, thin separators, small badges, and geometric markers over decorative illustration.

## Spacing and alignment
Use a strong outer margin, a consistent title band, and aligned card grids. Keep dense content inside dashboard or table regions.

## Animation / FX / Static fallback
HTML may use element animation, slide FX, and runtime transitions. Static SVG/PDF/PPTX exports ignore motion and preserve the final readable layout.

## Design guidelines
Lead with the case decision, pair every metric with an interpretation, and keep each slide anchored in AI operations platform startup pitch.

## Dos and don’ts
Do use concrete domain words such as OpsPilot, AI, incident, playbook, automation, platform. Don’t use generic filler, vague placeholder copy, or ungrounded claims.
