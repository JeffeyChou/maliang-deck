# Academic ML Report

## Use cases and case summary
Attention Routing Mechanism Explainer supports machine-learning mechanism explainer for applied ML researchers and graduate seminar reviewers. A research group explains attention routing, ablation evidence, and limitations for long-context summarization.

## Typography
Use Source Serif 4 for headlines, Inter for body copy, and JetBrains Mono for metric labels or code-like annotations.

## Palette and color system
Primary #172554, secondary #EFF6FF, accent #7C3AED, and neutral #475569. Use accent sparingly for attention signals.

## Component and material system
The system includes hero bands, evidence cards, metric charts, decision tables, and three-pillar operating model cards.

## Table and chart styling
Charts use the accent color for priority bars. Tables use high-contrast headers and concise cells tied to attention, routing, ablation, summarization.

## Icon and shape system
Prefer simple rounded rectangles, thin separators, small badges, and geometric markers over decorative illustration.

## Spacing and alignment
Use a strong outer margin, a consistent title band, and aligned card grids. Keep dense content inside dashboard or table regions.

## Animation / FX / Static fallback
This template is static-first. If HTML motion is added later, document the static SVG/PDF/PPTX behavior before approval.

## Design guidelines
Lead with the case decision, pair every metric with an interpretation, and keep each slide anchored in machine-learning mechanism explainer.

## Dos and don’ts
Do use concrete domain words such as attention, routing, ablation, summarization, tokens, model. Don’t use generic filler, vague placeholder copy, or ungrounded claims.
