# Executive Consulting

## Use cases and case summary
Northstar B2B SaaS Market Entry supports B2B SaaS market-entry strategy consulting for CEO, CRO, and board strategy committee. A consulting team sizes the DACH opportunity, compares channel economics, and recommends a focused enterprise wedge.

## Typography
Use Aptos Display for headlines, Aptos for body copy, and IBM Plex Mono for metric labels or code-like annotations.

## Palette and color system
Primary #102A43, secondary #F7FAFC, accent #2F80ED, and neutral #52616B. Use accent sparingly for SaaS signals.

## Component and material system
The system includes hero bands, evidence cards, metric charts, decision tables, and three-pillar operating model cards.

## Table and chart styling
Charts use the accent color for priority bars. Tables use high-contrast headers and concise cells tied to SaaS, DACH, enterprise, channel.

## Icon and shape system
Prefer simple rounded rectangles, thin separators, small badges, and geometric markers over decorative illustration.

## Spacing and alignment
Use a strong outer margin, a consistent title band, and aligned card grids. Keep dense content inside dashboard or table regions.

## Animation / FX / Static fallback
This template is static-first. If HTML motion is added later, document the static SVG/PDF/PPTX behavior before approval.

## Design guidelines
Lead with the case decision, pair every metric with an interpretation, and keep each slide anchored in B2B SaaS market-entry strategy consulting.

## Dos and don’ts
Do use concrete domain words such as SaaS, DACH, enterprise, channel, ARR, market. Don’t use generic filler, vague placeholder copy, or ungrounded claims.
