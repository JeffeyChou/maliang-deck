# Healthcare Biotech Briefing

## Use cases and case summary
TriageAI Diagnostic Validation supports clinical workflow optimization and diagnostic AI validation for hospital operations, clinical governance, and biotech partners. A clinical team presents diagnostic validation, workflow impact, and safety gates for emergency triage AI.

## Typography
Use Nunito Sans for headlines, Inter for body copy, and IBM Plex Mono for metric labels or code-like annotations.

## Palette and color system
Primary #0F3D3E, secondary #F8FAFC, accent #22C55E, and neutral #64748B. Use accent sparingly for triage signals.

## Component and material system
The system includes hero bands, evidence cards, metric charts, decision tables, and three-pillar operating model cards.

## Table and chart styling
Charts use the accent color for priority bars. Tables use high-contrast headers and concise cells tied to triage, diagnostic, sensitivity, specificity.

## Icon and shape system
Prefer simple rounded rectangles, thin separators, small badges, and geometric markers over decorative illustration.

## Spacing and alignment
Use a strong outer margin, a consistent title band, and aligned card grids. Keep dense content inside dashboard or table regions.

## Animation / FX / Static fallback
This template is static-first. If HTML motion is added later, document the static SVG/PDF/PPTX behavior before approval.

## Design guidelines
Lead with the case decision, pair every metric with an interpretation, and keep each slide anchored in clinical workflow optimization and diagnostic AI validation.

## Dos and don’ts
Do use concrete domain words such as triage, diagnostic, sensitivity, specificity, workflow, clinical. Don’t use generic filler, vague placeholder copy, or ungrounded claims.

## Reference inspiration and provenance
This pack is a synthesized Maliang Deck design inspired by common clinical workflow optimization and diagnostic AI validation communication patterns; it is not a pixel copy of any single reference.
