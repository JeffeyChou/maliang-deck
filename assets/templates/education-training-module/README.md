# Education Training Module

## Use cases and case summary
Data Literacy Onboarding Sprint supports data-literacy onboarding and training module for new operations managers and enablement facilitators. A training module teaches metric definitions, cohort reading, dashboard critique, and action planning.

## Typography
Use Nunito for headlines, Inter for body copy, and JetBrains Mono for metric labels or code-like annotations.

## Palette and color system
Primary #312E81, secondary #EEF2FF, accent #FBBF24, and neutral #6B7280. Use accent sparingly for literacy signals.

## Component and material system
The system includes hero bands, evidence cards, metric charts, decision tables, and three-pillar operating model cards.

## Table and chart styling
Charts use the accent color for priority bars. Tables use high-contrast headers and concise cells tied to literacy, cohort, dashboard, metric.

## Icon and shape system
Prefer simple rounded rectangles, thin separators, small badges, and geometric markers over decorative illustration.

## Spacing and alignment
Use a strong outer margin, a consistent title band, and aligned card grids. Keep dense content inside dashboard or table regions.

## Animation / FX / Static fallback
This template is static-first. If HTML motion is added later, document the static SVG/PDF/PPTX behavior before approval.

## Design guidelines
Lead with the case decision, pair every metric with an interpretation, and keep each slide anchored in data-literacy onboarding and training module.

## Dos and don’ts
Do use concrete domain words such as literacy, cohort, dashboard, metric, facilitator, onboarding. Don’t use generic filler, vague placeholder copy, or ungrounded claims.

## Reference inspiration and provenance
This pack is a synthesized Maliang Deck design inspired by common data-literacy onboarding and training module communication patterns; it is not a pixel copy of any single reference.
