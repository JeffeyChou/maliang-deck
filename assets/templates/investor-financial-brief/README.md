# Investor Financial Brief

## Use cases and case summary
HelioCloud Quarterly Metrics Update supports SaaS quarterly metrics and funding update for venture investors and finance leadership. A CFO reports ARR growth, retention, burn multiple, and the funding ask for an infrastructure SaaS platform.

## Typography
Use Manrope for headlines, Inter for body copy, and Roboto Mono for metric labels or code-like annotations.

## Palette and color system
Primary #052E2B, secondary #F0FDFA, accent #14B8A6, and neutral #64748B. Use accent sparingly for ARR signals.

## Component and material system
The system includes hero bands, evidence cards, metric charts, decision tables, and three-pillar operating model cards.

## Table and chart styling
Charts use the accent color for priority bars. Tables use high-contrast headers and concise cells tied to ARR, NRR, burn, runway.

## Icon and shape system
Prefer simple rounded rectangles, thin separators, small badges, and geometric markers over decorative illustration.

## Spacing and alignment
Use a strong outer margin, a consistent title band, and aligned card grids. Keep dense content inside dashboard or table regions.

## Animation / FX / Static fallback
This template is static-first. If HTML motion is added later, document the static SVG/PDF/PPTX behavior before approval.

## Design guidelines
Lead with the case decision, pair every metric with an interpretation, and keep each slide anchored in SaaS quarterly metrics and funding update.

## Dos and don’ts
Do use concrete domain words such as ARR, NRR, burn, runway, funding, SaaS. Don’t use generic filler, vague placeholder copy, or ungrounded claims.

## Reference inspiration and provenance
This pack is a synthesized Maliang Deck design inspired by common SaaS quarterly metrics and funding update communication patterns; it is not a pixel copy of any single reference.
