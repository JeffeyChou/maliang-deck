# Extracted Visual Design System

Source: prompt image **Image #1**. The screenshot shows a 20-slide presentation design-system overview. This project captures reusable tokens, slide archetypes, and a Maliang Deck sample deck.

## Core tokens

- Canvas: 1280 × 720, 16:9.
- Typeface: Inter / sans-serif.
- Primary palette: #0066FF, #3399FF, #66CCFF, #131927, #FFFFFF.
- Secondary palette: cool grays (#F3F6FB, #E5E7EB, #CBD5E1, #6B7280, #111827).
- Accent palette: #17AA71, #F6A21A, #6B5BEA, #E63888, #2FAEA2.
- Spacing rhythm: 14px baseline, 48px outer margin, compact 6–14px element gaps, 24–64px section gaps.

## Visual language

- White cards and slides with subtle #E5E7EB borders.
- Short blue underline beneath slide titles.
- Abstract blue wave artwork anchored bottom-right on cover/title and dark section slides.
- Footer convention: company name bottom-left, page number bottom-right.
- Rounded 4–8px controls, tags, and media cards.

## Extracted archetypes

- **Title Cover** (`title-cover`): Opening slide with left title and blue wave artwork.
- **System Reference** (`system-reference`): Dense design-system reference slide with numbered header and gridded modules.
- **One Column Content** (`one-column-content`): Title, accent underline, paragraph, bullets, footer.
- **Two Column Content** (`two-column-content`): Text column paired with a large right-side media block.
- **Three Column Cards** (`multi-column-content`): Three equal icon + heading + copy columns.
- **Large Media** (`large-media`): Wide media band with caption below.
- **Image Gallery** (`gallery`): Six rounded media tiles in 3x2 grid.
- **Chart or Table** (`chart-table`): Large table or chart area with standard title/footer.
- **Data Text Image** (`data-text-image`): Narrative, KPI/progress, and supporting image.
- **Dark Section Divider** (`section-divider`): Dark navy section break with section number, title, subtitle, and wave.
- **Centered Closing** (`closing`): Centered icon, thank-you headline, question prompt.

## Review caveats

The extraction is manual from a composite image rather than source PPTX/HTML. Use it as a reviewed draft template; exact source fonts, metrics, images, and small labels may differ.
