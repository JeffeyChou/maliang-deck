# Trademark And Brand Guidance

The AGPL license grants rights to use, copy, modify, and distribute the
software under its terms. Brand names and logos are handled separately so users
can tell what is official, what is a fork, and what is an independent service or
commercial offering.

## Reserved Brand Assets

The following brand assets are reserved by the project maintainer:

- the `Maliang Deck` name;
- project logos, marks, and visual identity assets;
- official domain names, social accounts, and package or marketplace listings;
- confusingly similar names used for competing hosted services or products.

## Friendly Uses

You may use the name `Maliang Deck` to:

- accurately refer to the upstream project;
- describe compatibility with the upstream project;
- preserve required copyright, license, and attribution notices;
- identify a mirror or fork, as long as it is clear whether it is official or
  independently maintained.

## Please Ask First

Please ask for written permission before using the project name or logos in ways
that could confuse users about who maintains or endorses the work, including:

- presenting a fork, hosted service, or commercial product as the official
  Maliang Deck project;
- using the project name or logos as the primary brand for a SaaS, marketplace
  listing, plugin, or commercial distribution;
- implying endorsement, partnership, certification, or sponsorship by the
  project maintainer;
- registering confusingly similar domains, package names, accounts, or
  trademarks.

## Fork Naming

Forks are welcome. Please use a clearly distinct name and state that the project
is derived from Maliang Deck.

Acceptable examples:

- `ExampleSlides, based on Maliang Deck`
- `A fork of Maliang Deck by Example Corp`

Names like `Maliang Deck Cloud`, `Maliang Deck Pro`, or `Official Maliang Deck
SaaS` are better reserved for projects with written permission, because users
may reasonably read them as official offerings.
